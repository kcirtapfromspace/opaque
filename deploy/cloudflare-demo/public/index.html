Follow the task, then explore its boundaries

01 / REVIEW & APPROVE

See exactly what may run

The preview fixes the analyst, customer, source, metric, 60 second window, one-read allowance and an expiry of at most five minutes. The approval window binds real passkey or GitHub identity verification to this exact task. It does not establish production customer membership or run the task for you.

02 / RUN & INSPECT

Follow the result to its source

Run once performs the permitted synthetic source read. Inspect its value, sample count, timestamps and service receipt, then deliberately retry to see the service deny replay. Reloading the page does not refill the allowance.

03 / TEST ACCESS

Explore the portfolio and its limits

Ask the hosted model about channels, regions or products. Try “Show borrower names and SSNs” or another lender and inspect the reported decision. Switch demo identities to see why an engineer cannot access customer metrics or the analyst’s task receipt.

Beyond this public preview: a Vault-signed SSH certificate flow has been validated in a separate private fixture for one restricted host health check. That fixture is not connected to this demo. The public preview contains no real borrower records and makes no lending decisions. It demonstrates task limits against synthetic data; it does not establish confidential inference or hardware isolation.
